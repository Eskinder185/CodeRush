# CodeRush 3 features in this branch

- Optional, skippable three-question onboarding saves a career goal, experience level, and daily minutes locally. It recommends an existing path.
- Five career journeys reuse the existing curriculum. Stage progress comes from recorded module completions; skipping never grants credit.
- Today plan suggests due command reviews, measured typing weaknesses, and the chosen path. It explains each suggestion from saved data.
- Linux free exploration now has a deterministic virtual working directory and fixed files. `cd`, `pwd`, `ls`, and `cat` depend on that virtual state. Learner input never reaches a real shell.
- Five missions cover a DNS service failure, failed DHCP lease, incorrect VLAN assignment, full Linux log filesystem, and suspicious Windows task. Evidence can be inspected in any order. Diagnosis, resolution, hints, and verification determine the score, which is saved locally.
- Quiz completion remains 50% for compatibility. A quiz score of at least 80% is now required for module mastery.
- Mission totals and achievement use recorded results. Progress history uses cards on phones. Imports show validation, duplicate counts, and merge/replace impact before applying.
- The version 3 storage key migrates CodeRush 2 data while retaining the old key as a backup. CodeRush 1 and 2 export formats remain importable.

Existing lessons, commands, paths, scenarios, typing modes, daily challenges, and local data portability remain available.
